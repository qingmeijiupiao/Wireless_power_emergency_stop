# emergency_remote

ESP32-C3 无线急停控制任务。优先级为 5，10 ms 节拍；ISR 锁存与发送代际取消均不依赖
UI、ADC、Shell 或控制台输出。接收回调只发布固定队列/最新值邮箱，控制状态由 worker
单一更新，UI/Shell 通过 `snapshot()` 读取完整副本。

## 关断确认与超时

启动、STOP、用户重试和重新配对建立 OFF 意图。关断总期限使用 `connect_ms`，默认
10000 ms，范围 1000～60000 ms；单次应答等待使用 `off_ack_ms`，重试间隔使用
`off_retry_ms`。期限从本轮关断开始计算，收到遥测、单次发送失败或信道恢复不会续期。

| 阶段 | 行为 | 休眠条件 |
|---|---|---|
| 等待本轮 OFF 确认 | 保留关断意图，重试与信道恢复；禁止 ON 越过 OFF | 忙状态阻止休眠 |
| 匹配的 OFF 业务确认成功 | 清除关断意图，发布输出关闭证据 | 无其他阻塞且证据新鲜 |
| 关断总期限耗尽 | 取消旧业务发送、停止无线与重试，置 `stop_timed_out` | 完成静止握手后允许休眠 |
| 新 STOP/重试/触点变化 | 作废原静止结论；新的关断请求重新计时 | 必须重新满足以上条件 |

`stop_timed_out` 是产品允许休眠的策略，**不代表已确认关闭**。`output_on` 保留已知或
可能开启的状态；`output_confirmed` 和 `output_time_us` 表示输出证据，不能用
`connection_failed` 冒充 OFF 确认。USB、按钮、配对或新待办仍可阻止超时后的休眠。

## 开启与旧消息

- 触点稳定释放后仅在本轮 OFF 确认后允许 ON；启动时不自动 ON。
- ON 成功入队才消费意图并增加 `on_attempt`；入队失败允许在 `on_ack_ms` 内短时重试。
- ON 已投递而业务应答超时，转入有期限的 OFF 同步，不重放未知结果的 ON。
- 未确认 ON 保守锁存可能开启，旧 OFF 遥测不能清除。输出更新只接受当前数据请求 ID。
- 业务应答必须匹配当前事务 ID、动作和配对代际；超时/STOP 作废旧事务。
- 急停 ISR 立即取消发送旧代际。已排队业务及后续重传由链路任务丢弃；已交给射频驱动
  的帧可能到达对端，取消无法撤回这种帧，OFF 紧随其驱动完成发送。

## 诊断与依赖

控制与回调日志零等待写入 `app_diagnostics`，控制台输出及黑匣子捕获由低优先级任务执行。
队列满丢弃会累计计数，Shell `blackbox status` 可查看 `async_log_dropped`。

发送取消接口来自工程内的 [espnow_link 补丁](../../overrides/README.md)，不修改协议报文格式。
主机回归覆盖取消/重试/遥测交错；真实空口延迟和急停到业务确认时间仍需板上测量。
